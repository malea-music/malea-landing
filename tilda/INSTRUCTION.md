# MALEA → перенос лендинга на Tilda (HTML-блоки)

Готовые блоки лежат в папке **`tilda/out/`**. Это весь лендинг (цвета, шрифты,
анимация вступления, плеер, видео, карусель отзывов, формы) — нарезанный на
куски под лимит HTML-блока Тильды (~50 000 знаков). Картинки уже на `tildacdn`,
переносить их не нужно. Единственное, что требует загрузки, — **3 файла шрифтов**
(их нельзя вставить текстом, см. шаг 2).

Всё проверено в симуляции страницы Тильды: рендер 1-в-1 с оригиналом, шрифты
Leotaro/Circe грузятся, кино-анимация вступления (deck) работает и стоит ровно
вверху страницы даже с обёртками Тильды.

---

## Что в папке `tilda/out/`

| Файл | Что это | Куда |
|---|---|---|
| `01-styles-01.html` | CSS, часть 1 (≈45K) | HTML-блок №1 |
| `01-styles-02.html` | CSS, часть 2 (≈45K) | HTML-блок №2 |
| `01-styles-03.html` | CSS, часть 3 (≈4K) | HTML-блок №3 |
| `02-markup-01.html` | Разметка страницы (≈38K) | HTML-блок №4 |
| `03-script.html` | Весь JS одним бандлом (≈28K) | HTML-блок №5 |
| `_SIZES.txt` | Отчёт о размерах | — |

**Порядок блоков на странице важен:** сверху вниз —
`styles-01 → styles-02 → styles-03 → markup-01 → script`.

---

## Шаг 1. Создайте «чистую» страницу в Тильде

Лендинг рассчитан на то, что он — **вся страница** (свой фон на `body`, своя
фикс-навигация, секции на весь экран). Поэтому:

1. Создайте новую страницу.
2. В настройках страницы **отключите хедер и футер Тильды** (либо не добавляйте
   их блоки). Хедер MALEA уже встроен в разметку.
3. Не добавляйте на эту страницу никакие другие блоки Тильды, кроме пяти
   HTML-блоков ниже. Глобальные стили лендинга (сброс отступов и т.п.) затронут
   всё на странице — поэтому страница должна содержать только наш лендинг.

> HTML-блок в Тильде называется **«T123 / HTML-код»** (Другое → HTML-код).

---

## Шаг 2. Загрузите шрифты и впишите их адреса

Шрифты Leotaro и Circe — бинарные файлы (~1 МБ), их нельзя вставить в текстовый
блок. Нужно дать им публичный адрес. Выберите один путь:

- **Проще всего:** если лендинг уже опубликован по адресу в интернете — возьмите
  ссылки на файлы прямо оттуда (папка `/assets/fonts/`).
- **Иначе:** загрузите 3 файла из `assets/fonts/` в Тильду
  (Настройки сайта → «Шрифты» → добавить свой шрифт, или любой файловый хостинг)
  и скопируйте полученные URL.

Файлы шрифтов: `Leotaro-Regular.otf`, `circe.ttf`, `circe-light.ttf`.
(По желанию можно сконвертировать их в `.woff2` — будет легче и совместимее;
тогда поправьте и расширения, и `format()` в CSS.)

Затем в файле **`01-styles-01.html`** найдите и замените 3 плейсхолдера на ваши
адреса:

```
__FONT_BASE__/Leotaro-Regular.otf   →  https://…/Leotaro-Regular.otf
__FONT_BASE__/circe.ttf             →  https://…/circe.ttf
__FONT_BASE__/circe-light.ttf       →  https://…/circe-light.ttf
```

Если все три файла лежат в одной папке — достаточно один раз заменить
`__FONT_BASE__` на адрес этой папки (во всех трёх местах сразу).

> Если шрифты не подставить — текст отрисуется запасным Cormorant/Helvetica,
> и фирменная типографика изменится.

---

## Шаг 3. Вставьте пять HTML-блоков по порядку

Для каждого файла:

1. Добавьте блок **HTML-код (T123)**.
2. Откройте файл из `tilda/out/`, скопируйте **всё содержимое** и вставьте в поле
   кода блока.
3. Расположите блоки на странице строго в этом порядке (сверху вниз):

```
1) 01-styles-01.html   (<style> …)
2) 01-styles-02.html   (<style> …)
3) 01-styles-03.html   (<style> …)
4) 02-markup-01.html   (разметка)
5) 03-script.html      (<script> …)
```

Почему именно так:
- три `<style>`-блока идут первыми, чтобы стиль применился сразу (без мигания);
  визуальной высоты они не добавляют;
- блок разметки должен идти **до** скрипта — чтобы к моменту запуска JS вся
  разметка уже была на странице;
- скрипт — последним.

---

## Шаг 4. Опубликуйте страницу

Код в HTML-блоках **работает только на опубликованной странице** — в режиме
редактирования/превью Тильды он показывается как текст. Нажмите «Опубликовать» и
проверьте на реальном устройстве (особенно анимацию вступления на десктопе и
мобильном).

---

## Если что-то пошло не так

- **Над лендингом появился пустой отступ / анимация вступления «сползла».**
  Значит блок над разметкой добавил высоту. Уберите лишние блоки/хедер Тильды.
  Анимация вступления требует, чтобы блок разметки был первым видимым элементом
  страницы (см. Шаг 1). В крайнем случае переместите три `<style>`-блока и
  `<script>`-блок ПОД блок разметки (появится короткое мигание при загрузке, но
  вступление встанет ровно вверху).
- **Шрифт не тот.** Проверьте Шаг 2 — адреса шрифтов и что файлы реально
  открываются по ссылке.
- **Видео/картинки не видны.** Они грузятся с `tildacdn`/`kinescope` — проверьте,
  что страница открыта по https и нет блокировок.
- **Анимация вступления не запускается на десктопе.** Она включается от ширины
  ≥1101px с мышью (`pointer: fine`) — это by design (на узких экранах вступление
  становится обычными секциями).

## Как пересобрать (если правите исходники)

Блоки сгенерированы из исходных файлов лендинга. После любых правок в `css/`,
`js/` или `index.html` пересоберите:

```
node tilda/build-tilda.js      # пересобирает tilda/out/*
node tilda/_make-preview.js    # (опц.) собирает tilda/_preview-test.html для локальной проверки
```

`tilda/_preview-test.html` можно открыть локально — он показывает собранный
результат (со шрифтами из `assets/fonts/`) ещё до вставки в Тильду.
